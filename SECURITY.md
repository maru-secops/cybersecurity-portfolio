# Security Policy

## Scope

This repository serves as an educational and professional cybersecurity portfolio containing sanitized case studies, lab notes, and defensive automation scripts.

## Operational Security (OpSec) & Data Hygiene

* All IP addresses, hostnames, and log records in this repository are synthetic or anonymized in accordance with **RFC 5737** (`192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`).
* Raw packet captures (`.pcap` / `.pcapng`) containing live network traffic or personally identifiable information (PII) are excluded from version control.

## Reporting an Issue

If you identify any unintended exposure of sensitive metadata, broken links, or security flaws in the provided code examples, please open a GitHub Issue or contact the repository maintainer directly.
